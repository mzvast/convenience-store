# 小小便利店 · LITTLE MART

基于 Three.js 的第三人称便利店购物游戏。参考青绿橙色招牌、暖光货架、玻璃门和紧凑店面的微缩模型。

## 本地运行

使用 Node.js 22 或更新版本，在本目录运行 `npm run dev`，打开 http://127.0.0.1:4173 。无需安装依赖。

## 游玩方式

- WASD 或方向键行走；点击地面自动寻路。触屏使用左下方向键。
- 点击货架商品，角色走到货架前拿起商品。靠近商品后也可按 E。
- 查看旋转包装、规格、说明和价格；点击“放入购物车”，或按 R 放回原货位。
- 点击购物车的加减按钮调整数量。所有单位对应场景中的实际库存。
- 带着购物车走近右前方收银台，机器人小麦自动扫描商品并打印小票。“去收银台结账”按钮可引导角色走过去。
- 右键拖动旋转镜头，滚轮缩放；方块按钮切换角色跟随视角。
- 音效默认关闭，可通过右上音效按钮开启。

全部支付均为游戏内模拟。商品品牌和价格为本应用的原创游戏内容。库存与小票保存在当前页面会话中，刷新后重置。

## 实现与验证

`dist/` 为完整静态应用，可直接静态托管。Three.js 0.180.0 随应用分发，许可证保存在 `dist/vendor/THREE-LICENSE.txt`。商品采用几何模型与本地 Canvas 包装纹理，包含瓶身、瓶盖、罐口、拉环、纸盒折顶和零食袋封边。应用需要 WebGL 2。

运行 `npm test` 检查拿取归还、购物车金额、库存一致性及重复结账保护。按用户要求，实现后验证，未采用红绿灯测试流程。

字体可从 Google Fonts 加载，网络不可用时使用系统字体。Three.js、包装素材与核心购物流程均从本地文件加载。
